# Instagram-style app

Static web app. To put it on your phone:

1. Create a new GitHub repository and upload every file in this folder (including `.nojekyll`).
2. Repo Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main` / `(root)` -> Save.
3. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.
4. Open that link in Safari (iPhone) or Chrome (Android), then Share -> Add to Home Screen.
